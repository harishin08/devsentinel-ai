# Day 10: DevSentinel AI Health Dashboard

## Objectives
- Build a system health dashboard.
- Collect CPU, memory, and disk usage.
- Determine the overall system health status.
- Display and save health reports.

## Concepts Learned
- Using `psutil` to monitor CPU and memory.
- Using `shutil.disk_usage()` to measure disk usage.
- Creating reusable Python functions.
- Determining system health using threshold checks.
- Formatting reports with timestamps and system information.
- Appending reports to a file.

## Project Files
- `app/python/health_dashboard.py`
- `logs/health-dashboard.txt`
