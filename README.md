# DevSentinel AI

AI-Powered DevOps Automation and Monitoring Platform.

## Project Goal

DevSentinel AI is a learning and portfolio project that combines
DevOps, Cloud, DevSecOps, Monitoring, and Artificial Intelligence.

The project will gradually implement:

- Linux
- Git and GitHub
- Python
- Docker
- Jenkins
- AWS
- Terraform
- Kubernetes
- Ansible
- Prometheus
- Grafana
- Trivy
- LLMs
- AI Agents
